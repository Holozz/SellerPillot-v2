# ADR 005：受控工具与有界单 Agent

问题：模型需要访问事实和规则，但身份、SQL和实际执行权不能由模型决定。

决定：AgentScope Toolkit 注册参数模型并执行工具，应用层控制模型轮数、工具数、Token 与总时长；QuerySpec 只允许白名单指标和参数。经营数字走 FactCard，业务修改由独立确认接口承担。

备选：固定流程可覆盖明确报表，优先直接执行；自由 SQL 难以约束权限和成本；强制多角色增加调用开销，需对照证明收益后再引入。

证据：实际 AgentScope 包已运行工具调用合同测试，模型响应用 Mock；离线浏览器流程不冒充真实模型。真实模型成功率、费用和失败分布尚需冻结题集实测。
