# ADR 001：同仓库应用分进程

问题：文档解析和模型调用时长与普通经营接口不同，需要隔离资源并允许独立恢复。

备选：单 API 进程内执行；模块化单体分进程；按领域拆微服务。

决定：保留同仓库领域服务和 MySQL 权威数据，API、control、文档和 Agent 分进程。避免 HTTP 内重任务；权限与业务规则在 API、工具和 worker 间复用。

代价：仍需解决数据库与队列一致性、版本和进程退出；领域依然共享发布与数据库。没有多团队独立发布需求，不为项目规模增加微服务治理。

证据：本地合同测试与浏览器预览验证共用服务；MySQL/Redis 多进程验收目前受 Docker 启动故障阻断，不能声称生产隔离能力已经证明。
