# ADR 003：同版本双路检索与对照选择

问题：SKU/型号与自然语言条款需要不同召回，同时更新资料不能混用索引版本。

决定：BM25 和向量固定在同一 build，应用层按名次 RRF 融合，重排作为需测量成本的候选。不可变构建完整后发布指针；禁用先控制可见性，物理清理异步进行。

备选及代价：纯关键词便宜但语义改写可能遗漏；纯向量依赖模型且型号匹配不一定好；全文引擎增加服务；双路方案需要维护版本和额外存储。重排未配置时记录实际未应用，不把配置名当效果。

证据：hash 向量、本地 Qdrant 验证流程和来源过滤；它是词特征夹具，不能支撑语义 Recall 改善。默认策略的质量结论仍需真实 embedding 与人工标注题集。
