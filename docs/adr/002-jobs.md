# ADR 002：MySQL 状态与 Redis Streams 提示

问题：任务接受、消息投递、执行结果必须能在进程退出后对账。

备选：数据库轮询；Celery；直接 XADD；MySQL Outbox + Streams。

决定：数据库保存任务、尝试、租约和 outbox；Redis 提供至少一次唤醒。派发失败重试，消息重复通过数据库状态抑制，旧 Worker 通过 token 拦截发布；对账不能依赖 Redis 消息仍存在。

代价：自行维护控制循环、领取、租约与故障实验。并不承诺模型调用恰好一次；外部请求在响应丢失后可能再次计费。

证据：临时 SQLite 合同测试已执行重复派发、过期接管、旧 token、取消和部分流中断；它不证明 MySQL 锁或真实 Redis 认领。集成测试入口单独保存并跳过，等待实际服务可用。
