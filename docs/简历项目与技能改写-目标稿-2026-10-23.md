## 项目经历

### SellerPilot 多店铺经营管理系统｜个人项目

**项目介绍：**面向小型卖家的多店铺经营管理需求，独立开发商品管理、订单导入、销售统计与商品变更审批功能，支持订单数据接入、经营分析及人工确认修改，重点解决重复数据、统计查询开销和并发修改冲突问题。

**技术栈：**Java、Spring Boot、Spring Security、MyBatis、MySQL、Redis、Docker。

- **经营查询优化：**统一销售额、退款及订单数口径，处理多明细关联重复计数与多币种统计；针对大店铺区间聚合开销，结合 EXPLAIN ANALYZE 调整查询与联合索引。在百万条模拟订单、20 请求/秒的同环境对照中，将无应用缓存查询 p95 从 820ms 降至 460ms。
- **缓存与回源保护：**针对多人反复查询经营报表及热点缓存失效问题，采用店铺数据版本与规范化查询参数构造缓存键，保证版本递增与业务写入同事务提交；通过 Redis 重建租约、二次检查及聚合并发限制控制重复回源。在双实例、200 请求/秒的预热负载下，热点查询 p95 为 180ms，业务错误率为 0.05%。
- **并发审批一致性：**针对旧草稿覆盖新数据、重复确认和网络重试，结合商品版本校验、固定锁顺序与执行唯一约束，在短事务内提交商品修改、回执及审计；通过 100 个并发确认、A→B→A 和响应丢失重试实验，验证同一草稿仅生效一次，旧版本返回冲突，成功请求重试返回原回执。
- **订单导入与数据隔离：**基于 JWT 身份与店铺权限校验限制业务访问；通过文件哈希识别重复文件，以店铺内订单号和明细行号处理跨文件重复与更新，将 CSV 解析校验移出写事务，确保单文件数据、导入记录和版本递增原子提交，避免重复统计与错误数据部分入库。

### Deep Research Agent｜个人项目

**项目介绍：**面向需要多轮检索与资料整合的研究任务，开发支持任务规划、并行检索和证据整理的研究助手，通过 FastAPI 提供异步任务接口，使用 SSE 展示执行进度并生成研究报告。

**技术栈：**Python、asyncio、FastAPI、SQLite、NumPy、SSE、Docker。

- **任务编排与容错：**针对子任务依赖和外部 API 超时，基于 asyncio 实现 DAG 并发调度，通过 Semaphore 限制工具并发；结合任务状态持久化、失败重试与动态重规划处理执行中断，区分已完成步骤与待重试任务，减少重复执行。
- **上下文与证据管理：**针对多轮检索的信息冗余与上下文膨胀，采用 Embedding 相关性过滤与 TextRank 筛选检索片段，保留原文及来源信息；基于 SQLite 与 NumPy 实现共享证据存取与相似片段去重，为报告引用保留可核对的依据。
- **结果校验与评测：**通过审查环节检查报告事实依据、逻辑一致性和引用质量，将结构化输出解析与研究质量分开评估；构建 ResearchBench 题集，保存原始输出、失败样例及耗时，对比固定流程与多 Agent 方案的任务效果和调用开销。

## 专业技能

- **Java：**熟悉面向对象、常用集合、异常处理与反射；理解线程池、线程同步和 ThreadLocal，能够结合业务分析并发访问与资源竞争问题。
- **Spring Boot / MyBatis：**能够完成接口开发、参数校验、统一异常处理与数据库访问；理解 Spring 事务代理、回滚规则及常见事务失效场景。
- **MySQL：**理解索引、事务隔离级别、MVCC、行锁及日志机制，能够结合执行计划分析关联查询、索引选择和锁等待问题。
- **Redis：**熟悉常用数据结构及持久化机制，理解缓存穿透、击穿与雪崩；能够结合业务设计版本缓存、重建互斥、过期策略及受控回源。
- **Python / AI 应用：**能够使用 FastAPI、asyncio 开发异步服务，具备 Agent 工具调用、检索证据处理、上下文管理与评测实践。
- **JVM 与工程基础：**理解 JVM 内存结构、垃圾回收及类加载机制；能够使用日志、服务指标和压测结果定位问题，使用 Docker Compose 运行应用及依赖服务。
