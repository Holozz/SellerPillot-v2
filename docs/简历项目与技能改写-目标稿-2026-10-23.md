**SellerPilot 多店铺经营管理系统｜个人项目**　〔起止时间按实际改造期填〕

**项目介绍** 面向小型卖家的多店铺经营需求，独立开发商品管理、订单导入、经营统计与标题变更审批，支持运营人员核对销售数据、处理重复导入并追踪商品修改，重点保障统计准确性、缓存一致性与并发操作正确性。

**技术栈**：Java、Spring Boot、Spring Security、MyBatis、MySQL、Redis、Flyway、Docker

- **并发审批一致性**：针对重复确认、网络重试与旧草稿覆盖新数据，按店铺→草稿→商品的固定顺序加行锁，结合商品版本与执行唯一约束，在短事务内提交修改、回执与审计；覆盖重复确认、A→B→A 及响应丢失重试，旧版本返回冲突，成功请求重试返回原回执。〔并发结果待测〕
- **热点缓存重建**：针对热点失效与重复聚合，以规范化参数和数据版本构造缓存键，版本递增与业务写入同事务，版本和统计数据同快照读取；采用 Redis `SET NX PX` 租约合并重建，持锁后二次检查，原子校验标识释放，配合有限等待与回源并发限制保护数据库。〔重建次数、p95 待测〕
- **统计口径与查询性能**：按订单—明细粒度统一口径，以 `COUNT(DISTINCT)` 避免多明细放大订单数；销售额按明细金额扣除退款，币种分开、时间统一 UTC 左闭右开，结合 `EXPLAIN ANALYZE` 分析扫描行数与排序开销，调整 SQL 和联合索引。〔同环境优化前后 p95 待测〕
- **订单导入与数据隔离**：基于 JWT 身份校验目标店铺权限，业务读写均限定店铺范围；文件哈希识别重复文件，以店铺内订单唯一键与明细行唯一键处理跨文件重复与更新；事务外解析校验，单文件数据、导入记录与版本同事务提交，避免重复统计与部分入库。

**技能栏**

- **Java**：集合、线程池与并发工具；结合 jstack、日志及池指标定位线程阻塞与资源等待
- **MySQL**：索引与执行计划、隔离级别与 MVCC、行锁与锁等待、慢 SQL 定位
- **Redis**：常用结构与持久化；版本化缓存键、热点失效、重建互斥与受控回源
- **Spring / MyBatis**：接口开发、参数校验、统一异常处理；理解事务代理边界与回滚规则
- **工程**：Docker Compose、Flyway 迁移、k6 压测与指标观测、Git
